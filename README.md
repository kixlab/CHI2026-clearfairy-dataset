# ClearFairy Cognitive Decision Steps

A dataset of **417 inferred cognitive decision steps** from **12 designers** working on web interface design tasks in Figma. Each step pairs a concrete design action with the inferred rationale and progression behind it.

This dataset accompanies the paper *ClearFairy: Capturing Creative Workflows through Decision Structuring, In-Situ Questioning, and Rationale Inference* (CHI 2026).

- Paper (arXiv preprint): https://arxiv.org/abs/2509.14537
- Paper (ACM DOI): https://doi.org/10.1145/3772318.3791680

## Overview

ClearFairy captures creative workflows by structuring designer activity into discrete *decision steps*. For each step, the system infers three things:

| Field | Description |
|---|---|
| `decision_and_actions` | What the designer did, in natural language |
| `rationale` | Why the designer made the decision. Left empty when no sufficiently grounded rationale could be established for the step. |
| `progression` | How the step fits into the larger design progression |

This dataset releases the inferred decision steps for 12 study participants. Two task types were used:

- **`lab_website`** — design a research lab homepage (6 participants, 183 steps)
- **`shopping_site`** — design an e-commerce interface (6 participants, 234 steps)


Each `P*.json` file is a JSON array of decision step objects.

## Schema

```json
{
  "participant_id": "P01",
  "task_type": "lab_website",
  "step_index": 0,
  "decision_and_actions": "The designer created a new frame for a desktop-sized web interface and added a text element for the lab's name, 'PI LAB'. ...",
  "rationale": "The designer emphasized the importance of clearly displaying the lab's name to ensure that visitors immediately recognize the lab's identity. ...",
  "progression": "The design process began with setting up a desktop frame, followed by adding and styling the lab's name as the main title. ..."
}
```

| Field | Type | Description |
|---|---|---|
| `participant_id` | string | Anonymous participant identifier (`P01`–`P12`) |
| `task_type` | string | One of `lab_website`, `shopping_site` |
| `step_index` | integer | Zero-based ordinal position of the step within the participant's session |
| `decision_and_actions` | string | LLM-generated description of the concrete actions taken |
| `rationale` | string | Reasoning behind the decision. Empty when no sufficiently grounded rationale could be established (~17% of steps) |
| `progression` | string | LLM-inferred narrative of how the step fits the larger workflow |

See [`data/schema.json`](data/schema.json) for the formal JSON Schema.

## Quick start

```python
from pathlib import Path
import json

DATA = Path("data/decision_steps")
steps = [s for f in sorted(DATA.glob("*.json")) for s in json.loads(f.read_text())]

print(f"{len(steps)} steps from {len({s['participant_id'] for s in steps})} participants")
# 417 steps from 12 participants
```

Or use the helper:

```python
from scripts.load import load_dataset
steps = load_dataset()
```

## Anonymization and privacy

Decision step text was generated by an LLM from raw Figma action logs. Before release, all references that could identify participants, institutions, or third-party products were replaced with **plausible fictional substitutes** rather than placeholders, so the natural reading flow of each step is preserved.

Specifically replaced:
- **People**: real participant names → fictional names
- **Institutions / labs**: real lab and university names → fictional ones (e.g., *Pinewood Interaction Lab*, *Northbridge University*)
- **Venues / papers**: real conference names and paper titles → fictional substitutes (e.g., *InterConf 2025*)
- **Brands and products**: real brand and product names from the shopping task → fictional brand names (e.g., *Spire*, *AcoustiCore*, *ATELIER29*)

Additionally:
- The original `timestamps` field linking steps to raw action logs has been removed.
- Participant demographic information (age, design experience, background) was collected during the study but is **not released** to minimize re-identification risk in a small (n=12) sample.

See [`DATASHEET.md`](DATASHEET.md) for the full collection and anonymization process.
